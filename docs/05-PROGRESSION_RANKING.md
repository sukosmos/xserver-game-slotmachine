# 05. 진행, 종료, 기록과 랭킹

## 5.1 Run 상태 머신
`ROUND_ACTIVE → (ROUND_CLEAR → SHOP | RUN_FAILED) → ROUND_ACTIVE → ... → RUN_WON`. `ROUND_CLEAR`는 정산 중의 트랜잭션 내부 단계이며, 10라운드 성공 시 상점 대신 `RUN_WON`으로 이동.
- `ROUND_ACTIVE`: Hand 남으면 Spin 가능.
- `ROUND_CLEAR`: 목표 이상이 된 스핀에서 보상을 계산하는 일시적인 정산 단계. Hand가 남아 있어도 `SHOP`으로 이동하며 R3는 먼저 `CARD_CHOICE`를 거친다. 최종 라운드는 `RUN_WON`으로 종료한다.
- `RUN_FAILED`: Hand 0이면서 라운드 점수 미달. 활성 비상 레버와 목표70% 이상 조건을 만족하면 레버를 소모해 일반 성공 정산으로 이동한다. 점수를 목표치로 올려주지 않는다.
- `RUN_WON`: 라운드10 성공 기록. v0.13은 자산을 보존하고 사용자가 선택하면 Endless로 계속 진행한다. 이전 규칙은 기존 종료 정책을 유지한다.
- `ROUND_CLEAR` 진입 시 **원자적으로 한 번만** 코인 정산.
- 상점에서 산 아이템은 다음 라운드부터 효과 적용.
- v0.11의 R3에서는 `ROUND_CLEAR → CARD_CHOICE → SHOP`을 거친다. 카드 선택 전에도 클리어 코인과 완료 라운드는 확정되지만 스핀/구매/다음 라운드는 차단한다.

## 5.2 라운드 목표
초기 목표 `[120,220,400,750,1400,2600,4800,9000,17000,32000]`.
각 라운드는 점수 0에서 다시 시작, Hand 5회 재지급. 인벤토리, 코인, 런 누적 점수는 유지.

## 5.3 랭킹 비교
1. **완료 라운드 수**(`completedRounds`)가 높은 기록 우선.
2. 동률이면 **런 누적 점수**(`runTotalScore`) 높은 기록 우선.
3. 동률이면 서버 완료 시간(`endedAt`)이 빠른 기록 우선.

- 런이 실패하든 승리하든 서버가 결과를 확정한 시점에 기록 후보 제출.
- 사용자는 여러 런을 진행할 수 있으나 **일반 랭킹은 계정당 최고 기록 1개**만 표시(가정).
- 인증 체계는 기존 서비스 환경을 조사해 연결. 게스트 기능이 필요하다면 서버 발급 익명 ID로 별도 등재(기획 보류).
- 랭킹 값은 클라이언트가 전달한 숫자가 아니라 서버에 저장된 **신뢰 가능한 run 결과**에서 취득.

Phase 4에서는 실패/승리 확정과 최고 기록 갱신을 같은 DB 트랜잭션으로 처리한다. 점수는 정규화된 십진 문자열로 저장하며 문자열 길이→문자열 순서로 정렬해 SQLite 정수 범위도 넘을 수 있다. 중복 요청은 종료 시각을 갱신하지 않는다. 완전 동률인 서로 다른 계정은 runId 순으로 표시 순서를 안정화한다. 내부 계정 대신 불투명 playerId를 공개하고 일반 랭킹은 저장된 모든 규칙 버전을 포함한다(버전 표시). 로컬 계정은 서버 CLI에서 발급하며 게스트/외부 로그인 연동은 후속이다.

## 5.4 일일 챌린지(출시 이후 / 구현 계획 Phase 6)
- 시작 아이템 풀, 기본 시드, 게임 설정 버전을 같은 조건으로 고정.
- 일일 도전 랭킹은 날짜별 별도. UTC인지 서비스 지역 기준일지는 출시 전에 확정.
- 참가자의 선택과 액션 수가 달라지면 동일 초기 seed에서도 RNG 소비 경로가 달라질 수 있다. **동일 초기 조건 = 동일 결과 보장은 아님**.
- 무한 재시도를 허용하면 공정성이 약해지므로 일일 랭킹의 시도 횟수/기록 보존 규칙을 별도 결정.

## 5.5 Endless (v0.13)
- R10 성공 → 축하 안내 → `Endless Mode 시작` → R10 상점 → R11. 버튼을 누르기 전까지 승리 화면에 머문다.
- 아이템·코인·카드 보상·스트릭·다음 스핀 예약을 이어간다. Hand는 매 라운드 기존 규칙으로 재지급한다.
- 목표는 직전 목표의190%를 정수 올림: 32,000 → 60,800 → 115,520. `data/balance.v0.json`의 `round.endless`가 기준이다. 기본 스핀 점수나 라인 배당은 라운드마다 자동으로 증가하지 않는다.
- 이후에도 성공 → 상점 → 다음 라운드를 반복하고 실패 시 종료한다. 10라운드 승리 기록을 보존하고 최종 실패 시 더 높은 기록으로 갱신한다.
- 재시작 시 승리 선택 대기/Endless 상점/진행 중 라운드를 복구한다. 목표와 누적 점수는 정확한 정수다.
