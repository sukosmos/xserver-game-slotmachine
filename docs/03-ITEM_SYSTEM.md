# 03. 아이템 시스템 / 처리 순서

> **실행용 아이템 카탈로그:** `../data/items.v0.json`. 본 문서는 엔진 구현에 필요한 공통 해석 규칙을 정의한다.

## 3.1 분류 및 지속시간
- **permanent**: 해당 런 종료까지 유지. 최대 영구 슬롯 **8**(MVP 가정).
- **charged**: 효과가 실제 성공적으로 발동할 때만 charges 감소. 잔여 0이면 제거. 제한 아이템 슬롯 **2**(MVP 가정).
- **timed**: 아이템 구매 후 진행되는 실제 Hand N회 동안 활성. Hand 결과 처리 **이후** 횟수 감소, 0이면 제거. 제한 슬롯 2개를 charged와 공유.
- **unique**는 동일 아이템 1개만 가능. **stackable**은 카탈로그 `maxStacks`까지 허용. 같은 영구 아이템의 중첩은 **같은 아이템 ID의 슬롯 1칸**을 공유하며, 제한형은 각 구매가 1칸을 사용한다.
- 슬롯이 가득 찼을 때는 기존 아이템을 **환불 없이 버린 뒤** 구매 가능. 상점에서 교체 UI 필요.
- 구매한 전투/확률/정산 보상 아이템은 **다음 라운드부터** 적용. 단 `흥정의 달인` 할인은 구매 **직후부터 이후 상점 구매**에 적용(이미 결제한 상품에는 소급 할인 없음).

## 3.2 기본 아이템 10종 — 각 심벌당 2개
| 심벌 | 가중치 증가(가격, 상한) | 배당 증가(가격, 중첩 수식) |
|---|---|---|
| 체리 | `체리 농장`: +10(2코인, 최대 3) | `황금 수확`: 추가 +200%(3코인, 최대 3; 1개 ×3, 2개 ×5) |
| 레몬 | `레몬 과수원`: +9(2코인, 최대 3) | `레몬 시럽`: 추가 +150%(3코인, 최대 3; 1개 ×2.5) |
| 종 | `종 제작소`: +8(3코인, 최대 3) | `공명 망치`: 추가 +125%(3코인, 최대 3; 1개 ×2.25) |
| 다이아 | `보석 광산`: +6(4코인, 최대 3) | `보석 감정사`: 추가 +100%(4코인, 최대 3; 1개 ×2) |
| 세븐 | `세븐의 축복`: +4(5코인, 최대 3) | `행운의 왕관`: 추가 +75%(5코인, 최대 3; 1개 ×1.75) |

가중치 아이템은 **3라운드 종료 상점부터** 등장한다. 구매 후 다음 라운드 활성화 정책은 동일하다.

심벌의 가중치는 각 아이템이 지정한 **정수 가중치**만 추가하며, 최종 확률은 전체 가중치로 재정규화한다. `배당 증가`는 아이템 하나의 `effect.extraFactor`(분자 `num` / 분모 `den`)를 동일 심벌 한정으로 합산한다.

## 3.3 결과 조작 아이템 — 핵심 정의
| 아이템 | 작동 | 제한 | 가격 |
|---|---|---|---:|
| 기적의 손 | 후보 라인 존재 시 8% 확률로 **후보 라인 균등 선택** 후 빈칸 1개를 심벌로 변환 | 발동 2회 | 5 |
| 조커의 가면 | 중앙 칸을 와일드로 **판정** (외형 심벌은 그대로) | 다음 2 Hand | 5 |
| 고장 난 레버 | 현재 보드에 완성 라인이 0개면 30% 확률로 마지막 **열 전체** 재추첨 | 발동 3회 | 4 |
| 사기꾼의 카드 | 완성되지 않은 라인이 있으면 6% 확률로 가상 체리 3일치 라인 배당 1개 추가(실제 보드/당첨 라인 수 불변) | 다음 4 Hand | 4 |
| 미래의 거울 | 세븐 심벌이 전체 보드에 2개 이상 존재 시 10% 확률로 임의 비세븐 칸 1개를 세븐으로 변경 | 발동 2회 | 6 |
| 자석 장치 | 2개 일치 후보 라인 존재 시 12% 확률로 균등 선택한 후보를 완성 | 다음 5 Hand | 5 |
| 계산된 기적 | 최종 점수 증가량이 **양수인 후보만** 고려해 증가량 최대의 변환 선택, 5% 발동 | 발동 1회 | 8 |

`조커의 가면`은 물리적으로 칸을 바꾸지 않는 **판정 보조 아이템**이므로 다른 변환 효과와 공존 가능.

## 3.4 후보 라인 엄밀 정의
- 현재 보드의 8개 라인 가운데 **정확히 2칸이 동일 심벌, 나머지 1칸은 다른 심벌**인 라인을 수집.
- 후보 단위는 `(lineId, changeIndex, newSymbol)` 튜플. 한 수정이 여러 라인을 완성시키더라도 해당 튜플을 중복 제거하지 않음. 즉 **후보 라인**을 균등 추첨.
- 각 후보는 **동일 확률**. 체리·레몬·다이아 중 배당이 높은 쪽을 우선하지 않음.
- 예시 보드(행 우선): `🍒🍒💎 / 🔔🍋7️⃣ / 💎🔔🍋`의 후보: 위 가로(체리), 주대각선(레몬), 역대각선(다이아).
- 8%는 **후보 1개 이상 존재하는 Hand당 1회** 추첨하는 발동 확률. 후보 3개라면 각 후보로 변경될 무조건부 확률은 `0.08 / 3 ≈ 2.67%`.
- 효과 발동 후 보드 전체 8개 라인을 **다시 계산**. 다른 당첨 라인의 생성·소멸도 최종 점수에 반영.

## 3.5 단일 Hand 처리 단계(MVP 권장)
1. 가중치 아이템 반영 → 9칸 추첨.
2. 현재 유효 `조커`의 와일드 조건을 제외한 **원본 심벌**로 보드 조작 조건 검사.
3. **보드 조작 아이템은 Hand당 최대 1개만 실제 발동**. 엔진의 고정 순위 `reroll_last_column` → `best_candidate_edit` → `random_candidate_edit` → `seven_transform`을 우선 사용. 같은 그룹은 획득 순서 → item ID 오름차순. 유효한 아이템이 성공하지 않으면 다음 검사.
4. 조작 아이템을 처리한 후, Wild를 반영해 8개 라인을 판정.
5. 가상 배당 아이템 등 점수 전용 후처리 적용. 보드 변환이 아닌 보상만 수정하므로 3단계 제한과 별개.
6. 심벌 기본 점수 + 라인 점수 + 가상 배당을 계산.
7. 심벌 전용 배율 → 라인 특수 배율 → 전역 배율 적용. 정수 내림.
8. 점수/런 누적 점수 반영, 연속 당첨 스트릭 갱신, 발동형 charges 사용, timed 아이템 남은 Hand 차감.

**아이템 우선순위/중복 허용은 초기 설계 가정**이다. 여러 조작 아이템이 동시에 유효할 때 처리 결과는 항상 결정적이어야 한다. RNG draw 소비 순서도 테스트에 고정할 것.

Phase 2에서는 위 우선순위를 `balance.itemRules.boardModifierPriority`에서 읽는다. `계산된 기적`의 동률은 라인 정의 순서이며, 확률 가상 배당은 같은 Hand의 원본/후보/최종 평가에서 같은 발동 난수를 공유한다. 상세 소비 순서와 활성 라운드/스트릭 정책은 `10-DECISIONS.md` 10.6을 따른다.

## 3.6 시너지·위험 아이템
| 아이템 | 효과 | 가격/등급 |
|---|---|---|
| 공명의 종 | 실제 완성 당첨 라인 **2개 이상**이면 최종 점수 ×4 | 7 / 영웅 |
| 잭팟 왕관 | 세븐 라인 배당 ×10, 다른 심벌 라인 배당 ×1/2 | 10 / 전설 |
| 악마의 계약 | 심벌 기본 점수 0, 모든 **실제** 라인 배당 ×4 | 9 / 전설 |
| 연속 승부 | 실제 당첨 라인이 나온 연속 Hand 수 2번째부터 총점 ×(3/2)^(연속수-1), 지수 최대 4 | 5 / 희귀 |
| 변덕스러운 조커 | 발동 10%: 후보 라인 균등 선택 후 변환, 그 변환으로 선택한 라인의 점수 ×3 | 발동 2회 / 6 / 희귀 |

- `잭팟 왕관`은 `행운의 왕관`과 서로 다른 아이템. 전자는 세븐 특수배율, 후자는 세븐 기본 라인 강화.
- `악마의 계약`의 ×4는 **라인에만** 적용. 기본 점수는 0이고 가상 배당은 기본적으로 라인 배당 취급하지 않는다.
- `공명의 종`은 가상 당첨 라인을 '완성 당첨 라인 수'에 포함하지 않는다.
- `변덕스러운 조커`의 ×3은 선택된 `lineId`에만 적용(같은 수정으로 우연히 완성된 다른 라인에는 미적용).

## 3.7 범위 제외
- `파멸의 올인`, `정밀 레버`, `보험 증서` 등 베팅칩 전용 아이템은 베팅 시스템 도입 전까지 **아이템 풀에 넣지 않음**.
- 플레이어가 매 Hand 수동으로 아이템을 눌러 발동하는 UI는 없음. **자동 발동**이 기본.

## 3.8 Hand 아이템 (v0.8)
| 아이템 | 효과 | 가격/등급 |
|---|---|---|
| 여분의 손 | 다음 라운드부터 매 라운드 Hand +1, 최대 2개 중첩 | 5 / 희귀 |

`round_hands_add`는 영구 슬롯을 사용한다. `round.maxExtraHands=2`를 넘지 않으며, 라운드 시작에 확정된 총 Hand는 해당 라운드의 남은 Hand 보상 검증에도 사용한다. 폐기해도 이미 정산한 보상은 바뀌지 않는다.

아이템 설명의 배율은 분수 대신 퍼센트로 표시한다. 예: 3/2배는 점수 150%, 배당 추가 2배는 +200%. 실제 연속 승부 발동 알림은 서버가 계산한 ×1.5, ×2.25 등의 현재 배수를 보여준다.
