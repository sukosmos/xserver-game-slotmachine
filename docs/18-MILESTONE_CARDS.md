# 3라운드 카드 보상 (v0.11)

기본 보상은 3코인부터 라운드마다 +1이다. 목표는 120/220/400/750/1400/2600/4800/9000/17000/32000이다. 실행 데이터는 `balance.round.milestoneCards`이며 기존 저장 런은 시작 버전을 유지한다.

3라운드 성공 보상 지급 → ROUND CLEAR → 뒤집힌 카드3장 → 한 장 공개 → 상점 순서다. 카드마다 한 장씩 있고 서버 RNG가 한 번 섞는다. 선택 전 공개 응답에는 위치 ID만 들어가며 새로고침해도 배치가 유지된다. 선택 효과는 런 종료까지 적용하며 인벤토리 슬롯과 중첩 한도를 소비하지 않는다.

| ID | 이름 | 효과 |
|---|---|---|
| prune | 심벌 삭제 | 다음 스핀의 유효 가중치 비율로 심벌 하나를 삭제. 나머지는 비례 재정규화 |
| evolve | 전체 강화 | 연결된 배당5종 각각 한 개와 같은 점수·배당 강화 |
| wild | 영구 조커 | 선택 이후 매 라운드 첫 실제 스핀의 중앙 와일드 |

삭제 심벌은 기본 추첨·재추첨·결과 조작으로 돌아오지 않는다. 가중치 아이템과 세븐 추적기 예약도 복원하지 못한다. 기존 아이템은 자동 폐기하지 않고 상점 후보도 유지한다. 카드 선택은 다음 Hand 예약을 소비하지 않는다. 삭제할 심벌의 추첨에만 현재 예약이 반영된다.

전체 강화는 황금 수확/레몬 시럽/공명 망치/보석 감정사/행운의 왕관의 효과를 읽는다. 1칸 점수 +2/+4/+6/+10/+20, 라인 배당 +200%/+150%/+125%/+100%/+75%이며 보유 아이템과 합산한다. 계약의 기본점수0은 우선하고 고정 패턴/가상 보너스에는 추가하지 않는다.

영구 조커는 표면 심벌과 기본점수를 바꾸지 않는다. 구매형 조커와 겹쳐도 첫 Hand에 소모한다. 임시 와일드는 이미 와일드인 중앙을 제외한다. 재접속이나 비상 Hand에서는 재충전하지 않는다.

`CARD_CHOICE` 단계에서 스핀/상점/다음 라운드를 차단한다. `POST /api/game/v1/runs/:id/cards/choice`는 `{expectedRevision,slotId}`만 받고 소유권·revision·중복 키를 검증한다. 선택과 효과 적용·상점 생성은 같은 트랜잭션에서 저장한다. 원래 순서·시드·삭제 추첨 난수는 공개하지 않는다.

UI는 카드 결과를 잠깐 보여준 뒤 상점으로 이동한다. 영구 보상 요약과 심벌 강화 표에 적용 결과를 계속 표시한다.
