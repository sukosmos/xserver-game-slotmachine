# 12. 프로젝트 네이밍 제안

최종 프로젝트명은 **미확정**이다. 아래 이름은 창작 후보이며 **상표/게임/도메인 중복 검증을 하지 않았다**. 코드 패키지·DB에서는 당분간 `slot-roguelite` 같은 중립 ID를 사용한다.

| 후보 | 분위기 / 장점 | 비고 |
|---|---|---|
| **SPIN QUOTA** (스핀 쿼터) | 매 라운드 목표 점수(할당량)를 채우는 게임 규칙을 바로 전달 | **추천 1순위** |
| **NINE TO RUIN** (나인 투 루인) | 3×3의 아홉 칸과 파산 위기, 다크한 분위기 | 현 문서 가제 |
| **LAST HAND** (라스트 핸드) | 남은 Hand·조기 정산의 긴장감 강조 | 3~4 Hand 룰과 밀접 |
| **LUCK TAX** (럭 택스) | 운에 세금이 붙는 느낌, 작은 코인 경제와 어울림 | 게임 내 직접 '세금' 시스템은 없음 |
| **REEL BREAK** (릴 브레이크) | 슬롯의 확률/배당 규칙을 아이템으로 깨뜨리는 컨셉 | 아이템 중심 브랜딩 |
| **9칸의 계약** | 세븐·왕관·악마의 계약을 반영한 한국어 판타지 명칭 | 영문 명칭 별도 필요 |

**내부 코멘트:** 구현 명칭과 브랜딩 명칭을 분리해 두면 나중에 타이틀을 변경해도 데이터 모델을 갈아엎지 않아도 된다.
