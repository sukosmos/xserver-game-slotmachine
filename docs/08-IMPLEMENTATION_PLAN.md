# 08. Codex 작업 계획 및 단계별 수락 조건

## Phase 0 — 저장소 파악 / 실행 기반
- [ ] 기존 웹 프론트, 서버, 인증, DB, 테스트 프레임워크 파악 및 기록.
- [ ] `data/*.json` 스키마 검사 로더 구현. 잘못된 itemId / line index 오류 검출.
- [ ] 순수 `RandomSource` 인터페이스와 시드 재현성 테스트 준비.
- **완료:** 기존 빌드 유지, 규칙 데이터 로더/스키마 테스트 성공.

## Phase 1 — 3×3 슬롯 엔진
- [ ] 가중치 추첨 9칸, 8개 라인 검사, 기본 점수 계산.
- [ ] Hand 4개, 목표 점수/정산 조건, 10라운드 전환.
- [ ] BigInt/유리수 연산과 숫자 직렬화.
- [ ] 단위테스트: 당첨 0/1/다중라인, 교차 라인, 경계값.
- **완료:** 서버 또는 로컬 테스트 러너에서 4 Hand 라운드를 반복 재현 가능.

## Phase 2 — 아이템 엔진
- [ ] 심벌별 10종 가중치/배당 아이템부터 적용.
- [ ] `기적의 손` 균등 후보 선택 및 8% 발동, `조커의 가면`, `고장 난 레버` 순으로 구현.
- [ ] 공명의 종/잭팟 왕관/악마의 계약/연속 승부 적용.
- [ ] timed/charged 수명, 같은 아이템 중첩, 인벤토리 슬롯.
- **완료:** 아이템 적용 순서/스코어/중첩/만료 테스트 통과.

## Phase 3 — 경제/상점
- [ ] 목표 달성 후 조기 정산/남은 Hand 보너스/이자.
- [ ] 3개 상품 진열, 코인 차감, 무제한 구매, 리롤 1→2→3 비용.
- [ ] 저금통/VIP/흥정 등 경제 아이템.
- [ ] 소득·소비 트랜잭션 및 중복 요청 방어.
- **완료:** 0코인/잔돈 부족/슬롯 한도/무료 리롤/중복 클릭 통과.

## Phase 4 — 서버/DB/랭킹
- [ ] Run 상태와 이벤트 로그 영속 저장.
- [ ] 권한 검증/시드 보호/서버 권위 점수 계산/재접속 복구.
- [ ] 완료 라운드 → 누적점수 → 완료시각 순으로 랭킹.
- **완료:** 브라우저 devtools에서 점수를 변경해도 랭킹에 반영 불가.

## Phase 5 — UI 및 튜닝
- [ ] 3×3 슬롯, Hand 카운터, 목표 게이지, 누적 점수, 코인, 아이템 표기.
- [ ] 당첨 라인 하이라이트, 아이템 조작 전/후 연출, 큰 점수 증가 피드백.
- [ ] 상점 구매/새로고침/정산 UX, 반응형, 모션 최소화.
- [ ] 10,000회 이상 자동 런 시뮬레이션으로 round별 성공률·상점 수익·아이템 파워 분석.
- **완료:** 1라운드~실패/10라운드 승리와 랭킹 제출까지 E2E 통과.

## Phase 6 — 출시 이후(별도 요청)
- [ ] 동일 조건 일일 챌린지 / 재시도 제한.
- [ ] 10라운드 이후 무한 모드.
- [ ] 베팅칩 설계 재검토(현재 금지).
