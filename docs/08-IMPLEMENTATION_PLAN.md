2026-10-26: Phase 3 완료. 모든 소득·소비와 상점 진입을 메모리 세션의 한 액션으로 처리한다. 구매·폐기·리롤은 SHOP에서만 허용하며 코인·진열·난수·응답을 v3 감사 로그로 재현한다. `npm run demo:shop`은 공개 테스트 시드로 자동 구매/리롤까지 진행한다. 운영 DB의 내구성·다중 프로세스 동시성·인증은 Phase 4 범위다.
