# 01. 게임 비전 및 기본 루프

## 한 문장 피치
**단 네 번의 슬롯 스핀으로 생존 목표를 넘기고, 작은 코인을 모아 확률과 배당을 왜곡하는 아이템을 사서 점수를 폭발시키는 웹 로그라이트.**

## 플레이 경험 목표
1. 한 번의 조작은 **SPIN 클릭 한 번**. 별도 실시간 입력이나 플리퍼 조작 없음.
2. 꽝에서 희귀 조합까지 결과 분포가 크고, 아이템이 이를 극적으로 증폭한다.
3. '희귀 배당을 노릴까, 보편 심벌을 강화할까, 경제에 투자할까'를 상점에서 결정.
4. 목표를 넘긴 뒤 바로 정산해 코인을 얻을지, Hand를 더 써서 랭킹 점수를 늘릴지 선택.
5. 실패 시 새 빌드로 다시 도전. 한 판의 아이템은 다음 판에 유지되지 않는다.

## 핵심 루프
`라운드 시작(점수0, Hand4)` → `스핀(확률 추첨·아이템·점수)` → `목표 점수 달성` → `조기 정산 또는 남은 Hand 스핀` → `코인 정산` → `상점(3슬롯·무제한 구매·유료 재추첨)` → `다음 라운드(Hand 리셋, 아이템·코인 유지)` → `실패 시 기록 제출`.

## 경쟁 콘텐츠
- **기본 랭킹:** 완료 라운드 수 내림차순, 동률이면 한 런의 누적 점수 내림차순.
- **일일 도전(후속):** 같은 초기 시드/아이템 풀/규칙에서 기록 겨룸. 주제별 밸런스와 다회 시도 정책 필요.

## 사용자가 재미를 느끼는 순간
- 세븐이 아슬아슬하게 빗나갔는데 낮은 확률의 `기적의 손`이 발동해 라인이 완성됨.
- 적립식 경제 아이템을 먼저 샀다가 상점에서 강력한 시너지 3개를 한 번에 구입.
- 목표 500점에 2 Hand가 남아 조기 종료 보너스 vs 기록 갱신을 선택.
- 배당 아이템끼리 결합해 고득점 연출(점수는 커져도 코인은 작은 단위 유지).

## 금지/주의
- 현금성 도박/결제/인출 기능 계획 없음. 게임 내부의 점수와 무상 코인만 사용.
- 도파민 연출은 빠르고 가독성 있게. 과도한 강제 대기, 페이투윈, 확률 은폐 금지.
- 개발 초반에는 복잡한 보드 개조나 베팅 자원 추가 금지.
