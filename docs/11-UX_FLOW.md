# 11. 화면 구조 / UX 플로우

## 11.1 화면 목록
1. **타이틀 / 새 런**: 시작, 최고 기록, 랭킹 진입.
2. **슬롯 화면**: 목표/현재/누적 점수, 3×3 슬롯, 남은 Hand, 코인, 장착 아이템, SPIN.
3. **당첨/아이템 효과 연출**: 당첨 라인 색상 강조, `기적의 손` 후보 표시→당첨 완성, 점수 단계 분해.
4. **목표 달성**: 성공 스핀에서 자동 정산하고 상점을 연다. 정산 버튼은 없다.
5. **라운드 정산**: 기본 + 잔여 Hand + 이자 + 경제 아이템 = 총 신규 코인.
6. **상점**: 코인 잔액, 3개 판매 카드, 가격/등급/효과/지속시간, 재추첨 비용, 다음 라운드.
7. **실패/승리**: 완료 라운드, 누적 점수, 달성 기록, 다시 시작, 랭킹.
8. **랭킹**: 계정별 최고 기록 1개, 라운드/점수/완료 시각.

## 11.2 슬롯 화면 간단 와이어프레임
```text
┌────────────────────────────────────┐
│ ROUND 03       목표 550 /  241 점  │
│ Hand ● ● ○ ○   누적 1,921   🪙 7   │
├────────────────────────────────────┤
│      🍒       🔔       🍋         │
│      🍋       🍒       💎         │
│      7️⃣        🍒       🔔         │
├────────────────────────────────────┤
│ 당첨 라인: -   마지막: +38        │
│ 효과: 체리 농장, 기적의 손 (1/2)   │
│ [SPIN]   [아이템 상세]             │
└────────────────────────────────────┘
```
*예시 숫자는 와이어프레임용 가상 텍스트.*

## 11.3 UI 우선순위
- 매 Hand마다 `보드`, `당첨 라인`, `원점수`, `아이템 효과`, `최종 점수`가 인과적으로 보여야 함.
- 숫자 과장 연출은 효과의 이유를 가리지 않도록. 설정에서 효과음/배속/모션 줄이기.
- 상점에서 같은 아이템의 중첩 수, 장착 슬롯/잔여 발동 수/유효 Hand를 명확히 표기.
- 코인/점수 단위는 확실히 구분(코인은 항상 정수 소액, 점수는 매우 커질 수 있음).
- 랭킹은 긴 점수를 축약 표시하고 전체 정수를 볼 수 있는 보조 정보 제공.

## 11.4 Phase 5 구현
기존 Node 서버의 정적 화면을 사용한다. 데스크톱은 왼쪽 게임 장면과 오른쪽 강화/아이템의 2열이며 좁은 화면은 게임 장면→강화 표→아이템 순서의 세로 배치다. 라운드 성공 후 왼쪽 머신 장면을 상점 장면으로 교체하고, 다음 라운드를 누르면 머신으로 돌아온다. 오른쪽 고정 상점과 라운드 중 상점 안내는 제거한다. 상단에는 라운드·누적 점수·코인·지난 런/새 런만 둔다. 아이템 도감 27종, 남은 수명/중첩/적용 라운드, 서버 구매 불가 이유를 표시한다.

당첨 라인과 변경된 칸을 표시하고 점수 상세에는 심벌 점수·라인·가상 배당·전체 배수·최종 점수·발동/만료 아이템을 보여준다. 보드 변화 보기로 원본/최종 보드를 비교한다. 큰 정수는 클릭 가능한 축약 숫자와 전체 숫자 대화상자로 제공한다. 게임 종료 시 랭킹은 서버에서 자동 갱신한다.

음향 기본 꺼짐, 빠른 연출/모션 줄이기, OS 모션 감소 설정, 키보드 포커스/대화상자/상태 알림을 지원한다. 응답 대기 중 게임 변경 버튼을 잠그고 연결 오류는 같은 명령으로 재시도한다. 지난 도전·새로고침·서버 재시작 후 복구를 지원한다. 실제 인수 기록은 [플레이테스트 보고서](14-PLAYTEST_REPORT.md)에 있다.

## 11.5 강화 확인 (사용자 피드백 반영)
- 심벌 다섯 종류의 `1칸 점수 / 3개 배당 / 추첨 확률`을 비교한다. 변경된 값만 원래 값→적용 값으로 강조한다. 심벌을 누르면 전체 정수·가중치 합·적용 아이템을 확인한다.
- 상점에서 `현재 / 다음 Rn`으로 전환한다. 구매·폐기 직후 다음 라운드 표를 갱신하고 실제 활성화와 구분한다. 라운드 시작 시 현재 적용으로 전환한다.
- 확률 발동·와일드·연속 당첨 등 조건부 효과는 기타 효과에 표시하고, 만료 시 제거한다.
- 동일 아이템은 한 카드와 중첩 수로 표시한다. 기존/새 스택이 함께 있으면 `적용 1 · 다음 1`로 구분하며 카드 상세에서 개별 인스턴스를 폐기한다.
- 상점/도감은 한 줄 효과 요약을 사용하고 설명 전문은 상세에 둔다. 일반 스핀 알림은 화면 읽기 프로그램에만 전달해 반복 배너를 줄인다.
