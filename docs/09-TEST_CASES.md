## 9.2 기적의 손 후보 검증
보드(행 우선):
```text
🍒 🍒 💎
🔔 🍋 7️⃣
💎 🔔 🍋
```
후보 라인 3개:
- `row_top`: 위치2 → cherry(30점 기본 라인)
- `diag_main`: 위치0 → lemon(60점 기본 라인)
- `diag_anti`: 위치4 → diamond(300점 기본 라인)

조건부 발동 확률 8%, 발동 시 후보라인 셋의 선택 확률 **각각 1/3**. 결과는 수정 이후 전체 8개 라인을 **재계산**해야 한다.

## 9.3 확률 시뮬레이션(밸런스)
- [ ] 초기 아이템 없는 상태의 9칸 심벌 분포가 가중치 비율에 통계적으로 근접.
- [ ] 기준 PRNG에서 4 Hand × 120점 통과율이 대략 0.9 부근인지 확인(허용 범위 0.87~0.93, 샘플 100k 이상 권장).
- [ ] 심벌 확률 조작으로 드문 고배당 조합의 빈도가 증가하는지 검증.
- [ ] 10라운드 누적 클리어율, 평균 코인, 아이템 채택 비율, 리롤 사용 횟수, score overflow를 기록.
- [ ] 3 Hand 대안은 같은 아이템/가격/목표와 별도로 시뮬레이션 후 비교; **그냥 Hand 수만 낮추면 난이도가 급상승**함.

## 9.4 경제 통합 시나리오
1. Run 시작: R1, score0, Hand4, coin0.
2. 1번째 Hand에 목표 통과 → 조기 정산: 보상 `2+3+0 = 5` coin.
3. 가격2 `체리 농장` 구입 → coin3, 재고 품절.
4. 유료 리롤 1회 → coin2, 상품3개 교체.
5. 상점 계속 → R2, Hand4, score0, coin2, 체리 농장 효과 유효.
6. R2 목표 실패 → 런 실패, 랭킹 결과는 완료한 라운드 1로 제출.

## 9.5 UI 인수
- Hand0 상태 Spin 버튼 비활성.
- 목표 미달 시 정산 버튼 비활성.
- 목표 달성 시 정산/계속 스핀 둘 다 보임(남은 Hand >0).
- 확률 조작/아이템 발동/만료를 스핀 결과 로그에서 확인 가능.
- 코인 가격 부족·인벤토리 부족 UI가 명확함.
