## 9.2 기적의 손 후보 검증
보드(행 우선):
```text
🍒 🍒 💎
🔔 🍋 7️⃣
💎 🔔 🍋
```
후보 라인 3개:
- `row_top`: 위치2 → cherry(30점 기본 라인)
- `diag_main`: 위치0 → lemon(60점 기본 라인)
- `diag_anti`: 위치4 → diamond(300점 기본 라인)

조건부 발동 확률 20%, 발동 시 후보라인 셋의 선택 확률 **각각 1/3**. 결과는 수정 이후 전체 8개 라인을 **재계산**해야 한다.

## 9.4 경제 통합 시나리오
1. Run 시작: R1, score0, Hand5, coin3.
2. 1번째 Hand에 목표 통과 → 자동 정산: 보상 `4+4+0 = 8` coin, 잔액11.
3. 가격3 `황금 수확` 구입 → coin8, 재고 품절. 가중치 상품은 R3 종료 상점까지 등장하지 않는다.
4. 유료 리롤 1회 → coin7, 상품4개 교체.
5. 상점 계속 → R2, Hand5, score0, coin7, 황금 수확 효과 유효.
6. R2 목표 실패 → 런 실패, 랭킹 결과는 완료한 라운드 1로 제출.
