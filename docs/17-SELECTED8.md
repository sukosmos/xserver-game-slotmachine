# 선택 신규 아이템 8종 — 후속 수정 포함 (v0.12)

출처는 사용자가 제공한 `spin-quota-selected8-v0.6`의 카탈로그와 엔진 계약이다. 원본16개 테스트 벡터는 `test/fixtures/selected8-vectors.json`, 아이템 원문은 `test/fixtures/selected8-catalog.json`에 보존한다. 실제 실행 데이터는 기존 `data/items.v0.json`에 병합한다. 현재 기본5 Hand·상점4칸·자동 정산 등과 충돌하는 과거 규칙은 [결정 기록](10-DECISIONS.md)의 10.14를 따른다.

거울은 기존 조작 뒤 마지막 물리 조작이며 실제 변경이 있으면 다른 물리 조작과 함께 발동하지 않는다. 임시 와일드는 v0.12에서 삭제하며 이전 저장에서만 당시 정책으로 재현한다.

모서리와 교차 보너스는 사각형과 함께 `patternScore`에 더한다. 패턴은 실제 라인/연속 당첨 횟수에서 제외하고 전역 배율만 받는다. 교차는 같은 칸을 중복 세지 않고 판정한 모든 칸을 표시하되 최대3칸만 지급한다. 편집자는 기본점수·패턴·가상 배당에 적용하지 않으며 다른 라인 유리수와 곱한 뒤 라인당 한 번만 내린다.

추적기는 예약 시의 인스턴스 ID와 목표 Hand 순번을 기록한다. 예약은 다음 추첨에서 한 번 소비하며 상점 구매/리롤/라운드 전환은 소비하지 않는다. 추적기 폐기/교체/런 종료는 예약을 제거한다. 영수증 카운터는 상점 경계를 넘어 유지하고, 해당 인스턴스 폐기 시 함께 사라진다.

비상 레버는 점수·Hand 차감 후 실패 직전에 목표70% 이상이면 라운드를 통과시킨다. 실제 점수는 그대로이며 정상 보상/상점/카드/최종 승리를 따른다. 목표100% 이상이면 사용하지 않고70% 미만이면 실패한다. 사용 시1충전이 사라지며 중복 요청으로 보상을 재지급하지 않는다.

화면은 새 와일드 위치, 모서리/교차 칸 강조, 예약 가중치, 구매 카운트/환급, 비상 레버의 ROUND SAVED을 서버 결과에서 표시한다. RNG/비밀 시드는 노출하지 않는다.
